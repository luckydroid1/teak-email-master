The Solution

A single PHP file that turns
Mailcow into a multi-domain powerhouse

One `index.php` deployed on your Mailcow server. No dependencies, no framework, no subscription.

👁️ Unified Dashboard
All Cloudflare domains auto-listed. Active in Mailcow = blue. Not added yet = gray + one-click add.
⚡ 1-Click Create
Select domain → type local-part → hit create. Auto-sets sender_acl, DKIM-ready attributes, Maildir format. 15 seconds vs 5 minutes in raw Mailcow UI.
📥 Live Inbox View
Click the inbox icon on any mailbox — see emails in real-time via Doveadm. Client calls asking "did I get that email?" → answer in 2 seconds.
🌐 Cloudflare Native
Auto-fetches all zones via CF API. No manual domain entry. 25+ domains, one list, zero config.
🔐 Session Security
Rate-limited login, HttpOnly+Secure+SameSite cookies, 1-hour session timeout, auto-logout on inactivity.
💰 Total Cost
$0 for the software. Runs on your existing Mailcow VPS. Zero monthly fee. Zero per-user fee. Zero vendor lock-in.
