# Build Plan: "Instant Clean Inbox for Builders & AI Agents" (Evolusi Mail Admin)

## Positioning
Evolusi dari `admin.php` (Mail Admin) menjadi platform SaaS: pengguna bisa buat inbox baru dalam 2 klik, terima email (OTP/code) di domain bersih, akses via REST API + MCP server untuk AI agents. Model bisnis: LTD (AppSumo) + non-expiring credits, top-up manual/belakangan.

## 1. Brand & Domain (Hybrid)
- **Rekomendasi brand: "CodeInbox"** (dual meaning: OTP *codes* + *code* = developer) — alternatif: InboxForge, AgentInbox, MailNook. Cek ketersediaan & beli 1 domain brand saat implementasi (rekomendasi TLD murah: `.dev`/`.app`/`.io`, hindari `.ai` yang $60-100/tahun).
- **Pool shared inbox**: domain Cloudflare yang sudah ada di Mailcow (jetdigitalpro.com, toohumid.com, jasa-seo.id, jdp.industries + bisa add dari 25 domain CF).
- Brand domain dipakai untuk: landing page, email verifikasi, dan pool inbox khusus produk (terpisah dari domain agency).

## 2. Stack (keputusan: PHP murni)
- PHP 8.3 + MySQL (database Mailcow yang sama, tabel baru dengan prefix `ia_`) + Nginx + Cloudflare Tunnel — **satu VPS yang sama, zero infra baru**.
- MCP server: Node.js + official `@modelcontextprotocol/sdk` (instal Node di VPS via NodeSource) — paling sedikit bug, well-documented, kompatibel Claude/Cursor.
- Frontend: server-rendered PHP + vanilla JS (konsisten dengan Mail Admin).

## 5. Fitur v1.0 (untuk launch AppSumo)
1. **Auth**: signup/login (email+password, bcrypt), email verification (kirim dari mailbox Mailcow existing), session hardening (lanjut dari admin.php)
2. **Credits + Redemption**: ledger-based, AppSumo code redemption (`/redeem` — validate, bind ke akun, grant credits)
3. **Inbox provisioning**: reuse logic Mailcow dari admin.php (INSERT mailbox + sender_acl + attributes maildir), pilih domain dari pool, konsumsi credits
4. **REST API** (Bearer API key): POST/GET inboxes, GET emails, GET email by uid, GET `/otp` (auto-extract code)
5. **OTP extractor**: parse text/plain + strip HTML → regex 4-8 digit code dekat keyword (code/OTP/verification/one-time/PIN) → JSON; fallback full text
6. **MCP server** (Node): tools list_inboxes, create_inbox, list_emails, read_email, get_otp — transport Streamable HTTP, proxy via nginx `/mcp/`
7. **Abuse prevention baseline**: rate limit (create inbox per jam, API calls), trust tiers (hari 0-3 quota kecil → naik bertahap → full setelah 60 hari), honeypot inboxes (admin@/postmaster@ → auto-ban IP + suspend user), risk scoring signup (IP, domain age, TLD), receive-only (no bulk send)
8. **Landing + Dashboard**: pricing page (copy dari chat), redeem page, dashboard (credits balance, inbox list, inbox viewer, OTP display), API keys page, MCP setup instructions

## 6. Fitur v1.1 (deferred — tercatat)
Webhooks, BYOD (DNS TXT verify), payment top-up (Stripe/LemonSqueezy), step-up ID verification, team seats, audit log UI, referral program.

## 8. Deployment
- Nginx vhost baru (subdomain brand atau `inbox.pesat.ai`) → `/var/www/inboxapp/public/`
- Deploy: tar + scp + extract (script `deploy.sh`), PHP-FPM socket yang sama
- Node MCP: systemd service, port 3456, proxy nginx
- Cron: honeypot watch (5 menit), retention cleanup (harian)

## 9. Verifikasi (regression)
- End-to-end: signup → verify email → redeem AppSumo code → credits masuk → create inbox (credits berkurang) → kirim test email → baca via API → OTP extract → MCP connect (simulasi via npx @modelcontextprotocol/inspector)
- Security: ulangi QA checks (SQLi, XSS, command injection, rate limit, session)
- Pastikan tidak ada credentials di repo public
